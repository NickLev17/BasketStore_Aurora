Добавление данных в таблицу Отвечает за добавление данных в таблицу базы данных.

Аргументы
tableName- имя таблицы, которую нужно создать или открыть.
title- название товара.
price- стоимость товара.
image- изображение товара.
caegory- категория товара.
description- описание товара.
rate- рейтинг товара.
voices- количество отметок пользователей.
Возвращает
true если запрос выполнен успешно, иначе false.

Вызывается из QML для создания/открытия таблицы из базы данных.
