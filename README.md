 # BasketStore_Aurora

 # Вашему вниманию представлено мобильное приложение "Корзинка", которое реализует взаимодействие пользователя с базой данных SQLite, через удобный и понятный интерфейс выполненный на языке QML, с использованием JS функционала.
 
 Мобильное приложение взаимодейтсвует с тестовым API интенет-магазина. Проект написан с использованием языков программирования С++,QML,JavaScript,SQL.
 Приложение имеет англо и русскоязычную версию.

  ## Базовый функционал приложения
-  Авторизация пользователя 
- Проверка авторизации
- Получение данных с интернет ресурса 
- Обработка данных, сортировка товаров по категориям
- Формирование карточек товаров
- Создание корзины товаров и истории покупок
- Работа с локальной БД на стороне клиента
- Сортировка данных по ценовой категории
- Анимирование элементов и кастомизация
  
 ## Принцип работы приложения
  При запуске приложения выводится информационное сообщение пользователю, с просьбой пройти авторизацию.
  ## Авторизация пользователя
  На странице авторизации необходимо заполнить основные поля: Ф.И.О., Email, и пароль. А также отметить ряд пунктов "Интересы пользователя" и "Согласия". После чего нажать на кнопку "Применить".
Для перехода на главную страницу достаточно ввести лишь Email и пароль. После проверки, пользователю становится доступной кнопка "Поехали", нажав на которую, осуществляется переход на страницу "Категории".
и "Корзина".
   ## Категории 
  Товары разделены на 4 категории:
  - Электроника
  - Мужская одежда
  - Женская одежда
  - Украшения
  - История покупок
  - Корзина
   При нажатии на кнопку любой из категорий, пользователь переходит на страницу с аасортиментом данной категории товаров (изображение товара, название, цена).
 Выводится список товаров и общее их количество в данной категории.
  При нажатии пользователем на любой товар, происходит переход на страницу "Карточка товара".
  ## Карточка товара
  В карточке товара указывается ее внешний вид (изображние), название, цена, рейтинг товара, количество голосов пользователей оценивших товар, а также описание товара.
После описания товара кнопки:
"Купить сейчас" и "В Корзину".
При покупке - товар помещается в раздел "История покупок".
При добавлении товара в корзину, пользователю становится доступным счётик товара, что удобно при добавлении в корзину.
Данные о истории покупок и корзины, хранятся в локальной базе данных SQLite на стороне пользователя.

   ## "История покупок" и "Корзина"
  На страницах "История покупок" и "Корзина", пользователю представлена вся информация о товарах, общая сумма затраченных средств на текущие и планируемые покупки. А также доступна сортировка товаров по ценовой характеристике.
Сортировка производится по возрастанию и по убыванию цены товаров. Пользователь может очистить историю покупок или корзину от товаров (локальная база данных тоже будет очищена). Также находясь на данных страницах можно перейти 
на страницу карточка товара докупить товаров или добавить в корзину.
